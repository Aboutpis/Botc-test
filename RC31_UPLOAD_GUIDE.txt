config.js, Firebase 보안 규칙, vote.js, grimoire.js, style.css, 공식 기본 JSON 3개는 변경하지 않습니다.

변경 사항
- 기존 기본 시나리오 3개 유지. 틴시빌 10개, 커스텀 10개를 별도 접기 목록으로 추가했습니다.
- 제공한 ZIP에서 한글 KO.json 20개만 포함했습니다. 영문 ORIGINAL.json은 포함하지 않습니다.
- 자동·수동·직접 뽑기 중 선택한 버튼은 버건디색과 체크 표시, aria-pressed 상태로 구분합니다.
- 참가자 모바일 대기실의 시나리오 제목을 확대하고 중복 ‘처음 화면’ 버튼을 제거했습니다.
- 참가자 밤 단계의 스크립트 버튼을 안내/질문 카드 바로 위 오른쪽으로 옮겼습니다.
- 사회자 밤·낮에서 ‘게임 종료’ 버튼이 있는 경우 하단의 ‘처음부터 다시 시작’은 표시하지 않습니다.
- 배분 단계의 취소·다시 설정은 유지합니다.
- 새 한글 제목과 역할 능력에 필요한 글꼴 글자를 CSS 안에 추가했습니다. 기존 Noto Sans KR 라이선스가 적용됩니다.

한글 파일 검증

- 역할 항목 총 382개(시나리오 사이 중복 포함), 한글본의 순서와 내용 보존.
- 이 자료는 비공식 한글화본입니다. 공식 번역이나 시나리오 최신판이라는 보증은 아닙니다.
- 여행자·우화·전승은 스크립트에서 별도 분류하여 표시합니다. 우화·전승은 배분 캐릭터 목록에서 제외합니다.
- 우화, 전승, 징크스, 역할 능력의 특수 규칙은 사회자가 진행합니다. 새 규칙 자동 판정 기능을 추가한 것은 아닙니다.
