시계탑에 흐른 피 · RC5.8.7.27 클래식 테마 적용본

이 파일은 실제 앱 배포용입니다. 디자인 미리보기나 가상 참가자는 포함하지 않습니다.

적용 방법
1. 기존 배포 파일을 백업합니다.
2. 이 ZIP을 풀고 index.html이 있는 폴더의 모든 파일과 theme-assets 폴더를 함께 업로드합니다.
   Netlify 수동 배포에서는 index.html이 바로 들어 있는 폴더를 업로드합니다.
   GitHub에서는 기존 저장소 루트에 같은 구조로 덮어씁니다.
3. 기존 사이트 주소로 접속한 후 한 번 새로고침합니다.
4. 사회자 1대와 참가자 2대로 입장→배분→역할 확인→밤 질문→낮→투표→종료를 확인합니다.

보존한 파일
app.js / vote.js / grimoire.js / config.js / Firebase 규칙 / 시나리오 JSON / style.css는
27 안정 버전과 바이트 단위로 동일합니다. Firebase 설정·규칙을 다시 입력할 필요가 없습니다.
기존 index.html의 스크립트와 자동 버전 확인 코드도 그대로 유지했습니다.
추가된 theme.css, theme-ui.js, theme-assets는 표시와 화면 크기에 따른 배치만 담당합니다.
앱 버전은 기능 기준 RC5.8.7.27로 유지합니다.

반영한 디자인
- 단계별 배경이 가로·세로 화면 전체를 채우고 화면 비율에 따라 일부가 잘립니다.
- 참가자 배분·역할 화면은 가로에서 가운데 카드 아래로 배치합니다.
- 사회자 가로 배분 패널은 오른쪽 영역만 스크롤합니다.
- 밤 사회자 가로 화면은 질문·응답 / 양피지 그리모어 / 밤 순서의 3분할을 유지합니다.
- 참가자 방 나가기와 사회자 게임 종료는 가로 오른쪽 위에 고정합니다.
- 늦은 오후 처형대 배경, 처형투표 안내판, 시계판·시침, 운명의 토큰을 적용했습니다.

원본 렌더러의 실제 화면 상태 40개를 세로 390×844, 가로 1280×800 및 1920×1200에서 점검했습니다.
화면 이동, 입장 입력, 역할 공개, 실제 분할 그리모어 편집, 회전 시 재배치를 확인했습니다.
검증 과정은 Firebase 연결을 대체한 로컬 환경에서 진행했습니다. 실제 다기기 연동은 배포 후 확인해야 합니다.
이 ZIP을 만드는 과정에서 기존 운영 사이트와 실제 게임 데이터는 변경하지 않았습니다.
