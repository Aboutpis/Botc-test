RC5.8.7.15 - 투표 전용 혼합 테스트

1. 사회자 방 생성 후 참가자 스마트폰 1~2대로 먼저 입장합니다.
2. 사회자 대기실에서 '투표 테스트 시작'을 누릅니다.
3. 낮 화면의 '더미 6명 포함' 체크 상태로 투표를 시작하면 실제 참가자 + 더미 6명이 참여합니다.
4. 더미는 테스트 1,3,5만 자동 찬성, 전원 자동 확인. 실제 참가자는 직접 찬성/확인합니다.
5. 체크를 끄고 다시 투표하면 실제 참가자만 테스트합니다.
6. 일반 게임 방은 기존 투표 흐름을 사용합니다.

주의: 이 버전은 투표 기능만 테스트합니다. 실제 여러 기기 및 Firebase 네트워크 환경 검증은 별도 필요합니다.
