RC5.8.7.29 — 처형투표 준비 문구 카운트다운

RC5.8.7.28을 기준으로 만든 전체 앱입니다. 테마는 추가하지 않았습니다.
28버전의 '보여줄 역할 작은 캐릭터 토큰 자동 생성' 기능을 포함합니다.

변경
- 투표 준비 5초 동안 시계 아래 문구가 5초 후 시작 → 4초 후 시작 → 3초 후 시작 → 2초 후 시작 → 1초 후 시작으로 표시됩니다.
- 가운데 숫자와 같은 서버 시간 기준의 남은 초를 사용합니다.
- 사회자·참가자 모두 적용됩니다.
- 준비가 끝나면 기존처럼 '현재 차례: 참가자 이름'으로 바뀝니다.
- 시침 회전, 준비 시간 5초, 참가자별 투표 시간 5초, 투표 버튼 활성화 및 집계는 그대로입니다.
- 변경 파일: vote.js(문구와 버전 표시), index.html(29버전과 캐시 번호), 이 안내 파일.
- app.js(28버전 기능), grimoire.js, style.css, config.js, 시나리오 및 Firebase 규칙은 28버전과 같습니다.

적용
1. ZIP 압축을 풉니다.
2. index.html이 있는 내용물을 기존 저장소 최상위에 덮어씁니다. .git은 그대로 둡니다.
3. 커밋·Push/동기화합니다.
4. Pages 배포 완료 후 모든 기기를 새로고침하고 하단 RC5.8.7.29를 확인합니다.
5. 새 방에서 투표를 시작하고 시계 가운데 숫자와 아래 문구가 함께 줄어드는지 확인하세요.
Firebase 설정·규칙 변경은 필요 없습니다.

검증
- JavaScript 문법 검사 통과.
- 사회자/참가자, 서버 시차, 초 경계, 투표 시작 및 결과 전환을 가짜 시간으로 검증했습니다.
- 28버전 app.js 완전 동일 확인.
- 투표 코드의 변경이 준비 문구와 버전 표시뿐임을 비교 확인했습니다.
- 실제 다중 기기 확인은 배포 후 수행하세요.
