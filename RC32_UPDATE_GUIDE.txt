원인
- 추가 한글 시나리오 JSON의 외부 이미지 주소가 404였습니다.
- 이미지를 숨기는 기존 처리 때문에 설명이 아이콘용 46px 칸으로 이동했습니다.

수정
- 20개 시나리오에 등장하는 서로 다른 캐릭터 121종의 정상 이미지를 scripts-ko.js 안에 포함했습니다.
- 참가자 역할 공개, 스크립트, 밤 순서, 사회자 역할 버튼, 그리모어 기본·추가 캐릭터 토큰이 같은 내장 이미지를 사용합니다.
- 이름과 능력, 역할 분류, 배분/질문/투표 규칙은 유지했습니다.
- 이미지를 포함한 것은 브라우저용 scripts-ko.js이며 Firebase에 저장하는 시나리오에는 이미지 데이터 용량을 추가하지 않습니다.
- 기존에 만들어진 방도 역할 ID가 일치하면 내장 이미지를 사용합니다.
- 별도 사용자 JSON에서 알 수 없는 이미지가 깨져도 이름이 있는 대체 토큰이 남도록 처리했습니다.
- 스크립트는 아이콘 칸과 설명 칸을 명시적으로 분리했습니다. 이미지가 없어도 설명 칸은 정상 너비를 유지합니다.
- 새 시나리오 제목·캐릭터 이름은 필요한 한글 글자가 들어 있는 글꼴로 표시합니다.

검증
- 외부 이미지 네트워크를 차단한 상태에서 20개 시나리오의 382개 역할 항목 전부 이미지 디코딩 성공.
- 360×740, 390×844, 1280×800에서 스크립트 설명·역할 공개 확인.
- 그리모어 기본 토큰과 옆의 추가 캐릭터 토큰 확인.
- 이미지 오류 시 대체 토큰 및 설명 너비 유지 확인.
- 사회자/참가자 2명 로컬 모의 DB로 방 생성, 배분, 자동 캐릭터 알람, 밤 질문/더미 답변, 낮 전환, 투표·결과 확인 통과.
- 실 Firebase 서버의 인증·규칙·네트워크는 위 로컬 테스트 범위 밖입니다.
