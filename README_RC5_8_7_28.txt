RC5.8.7.28 — 보여줄 역할의 작은 캐릭터 토큰 자동 생성

기준: GitHub RC5.8.7.27-STABLE 태그
추가 기능은 한 가지이며 테마는 추가하지 않았습니다.

예: 실제 역할 주정뱅이 / 보여줄 역할 점쟁이
배분 완료 후 사회자가 '첫 번째 밤 시작'을 누르면:
- 그리모어 큰 역할 토큰: 주정뱅이
- 그 옆 작은 캐릭터 토큰: 점쟁이 (자동 생성)
- 참가자에게 보이는 역할: 기존과 같은 점쟁이

동작
- 자동 배분, 수동 배분, 참가자 직접 뽑기 모두 적용됩니다.
- 실제 역할과 보여줄 역할이 다른 경우에 생성합니다. 주정뱅이에만 한정하지 않습니다.
- 보여줄 역할이 실제와 같거나 미지정이면 추가하지 않습니다.
- 기존에 수동 추가한 캐릭터 토큰과 생존/사망 상태는 유지합니다.
- 같은 보여줄 역할 토큰이 중복 생성되지 않습니다.
- 기존 '추가 캐릭터 토큰' 편집에서 작은 토큰을 삭제하거나 더할 수 있습니다.
- 첫 번째 밤 시작 때 한 번 저장하므로 삭제한 토큰을 매번 화면 갱신 때 다시 붙이지 않습니다.
- 저장 데이터는 기존 사회자 전용 경로를 사용합니다. Firebase 규칙을 바꿀 필요 없습니다.

적용 방법 (VS Code / GitHub)
1. ZIP 압축을 풉니다.
2. index.html이 있는 내용물을 기존 Botc-test 폴더 최상위에 덮어씁니다.
   별도의 하위 폴더 안에 넣지 마세요. .git 폴더는 그대로 둡니다.
3. 변경 내용을 커밋하고 Push/동기화합니다.
4. Pages 배포 완료 후 모든 기기에서 새로고침합니다.
5. 화면 하단 버전이 RC5.8.7.28인지 확인합니다.

변경 파일
- app.js: 첫 번째 밤 시작 시 작은 역할 토큰 저장
- index.html: 28버전 표시, 캐시 구분 번호
- 이 안내 파일 추가
style.css, grimoire.js, vote.js, config.js, 시나리오 JSON, Firebase 규칙은 stable 27과 동일합니다.

실제 기기 확인 (최소 사회자 1대 + 참가자 2대)
1. 새 방을 만들고 실제 주정뱅이 / 보이는 점쟁이로 설정해 배분합니다.
2. 참가자 화면에 점쟁이가 보이는지 확인합니다.
3. 첫 번째 밤으로 이동해 사회자 그리모어에 큰 주정뱅이 + 작은 점쟁이가 보이는지 확인합니다.
4. 사회자 새로고침 후에도 유지되는지 확인합니다.
5. 실제와 보이는 역할이 같은 참가자에게 불필요한 작은 토큰이 없는지 확인합니다.
6. 작은 토큰을 삭제한 뒤 다음 낮/밤에서 다시 생기지 않는지 확인합니다.

검증
- 원본 태그 소스와 보관된 27버전 소스의 주요 파일 일치 확인
- JavaScript 문법 검사
- 가짜 데이터베이스를 사용한 15개 자동 검사 통과
- 실제 Firebase 다중 기기 검증은 배포 후 위 순서로 확인하세요.
