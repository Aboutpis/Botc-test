RC5.8.7.6 테스트 빌드

중요: 이 버전은 새로운 Firebase Realtime Database 경로(public/vote, private/playerVoteRights)를 사용합니다.
함께 포함된 FIREBASE_RULES_RC5_8_7_6.json 규칙을 Firebase Realtime Database > 규칙에 적용해야 참가자 찬성/확인이 가능합니다.
현재 운영 중인 동일 Firebase를 사용하므로 테스트 방을 따로 만들어 진행하세요.

테스트
1. 사회자+참가자 2대 이상, 캐릭터 구성 완료 후 낮 단계로 이동.
2. 사회자 그리모어 5x5/6x6 테두리 배치, 중앙 드래그 금지, 토큰 여백 확인.
3. 낮에서 처형 투표 시작 → 후보 선택 → 시작 참가자 선택 → 확인.
4. 모든 화면에 이름만 보이는 시계, 준비 5초, 참가자별 5초, 찬성 버튼 확인.
5. 마지막 참가자 후 결과 → 사회자+참가자 전원 확인 → 낮으로 복귀, 후보/표 수 기록.
6. 같은 낮에 두 번째 투표 진행.

주의: 실제 여러 기기 Firebase 통합 테스트는 수행하지 않았습니다.
